Required

The folder's full path, starting with /. leaf creates the folder if it isn't there yet. Suggested: , inside leaf's data folder.

What a folder means

  • The files live only on this machine. Nothing is copied anywhere else.
  • There is no redundancy: if the disk fails or the folder is deleted, the archived photos and videos are gone. Back the folder up yourself.
  • In Docker, the folder must be inside the mounted data volume, for example /data/media. Anywhere else is inside the container, and the files vanish when the container is replaced.
